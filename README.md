# 📝 Lista de Tarefas

Aplicação simples de lista de tarefas feita com **HTML, CSS e JavaScript puro**, criada para praticar manipulação do DOM e armazenamento local no navegador.

## ✨ Funcionalidades

- Adicionar novas tarefas
- Marcar tarefas como concluídas (e desmarcar)
- Excluir tarefas
- As tarefas ficam salvas no navegador (`localStorage`), então não somem ao recarregar a página
- Campo vazio não adiciona tarefa

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript (ES6+)
- localStorage


## 🚀 Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/Dev-Gabriel-Oliveira/lista-de-tarefas.git
   ```
2. Entre na pasta:
   ```bash
   cd lista-de-tarefas
   ```
3. Abra o arquivo `index.html` no navegador (ou use a extensão Live Server do VS Code).

## 🧠 O que pratiquei neste projeto

- Seleção de elementos com `querySelector`
- Criação de elementos com `createElement` e `appendChild`
- Eventos de clique com `addEventListener`
- Arrays e objetos para guardar o estado das tarefas
- `JSON.stringify` / `JSON.parse` com `localStorage`
- Função para redesenhar a lista na tela (`renderizarTudo`)
